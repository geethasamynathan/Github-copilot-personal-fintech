# GitHub Copilot – Foundations & Architecture

## What is GitHub Copilot?
GitHub Copilot is an AI-powered coding assistant that helps developers write code faster, generate functions, debug issues, and learn new technologies.

---

## Why Use GitHub Copilot?
- Saves development time
- Reduces effort
- Improves productivity
- Helps beginners learn faster

---

## Architecture & Flow

1. Context Gathering
2. Pre-Model Filters
3. Proxy Service
4. AI Model Processing
5. Post-Model Filters
6. Output to IDE

---

## Installation & Setup

1. Install VS Code
2. Install GitHub Copilot Extension
3. Sign in with GitHub
4. Enable features

---

## Code Privacy & Safety

- Code is not used for training
- Data is encrypted
- Sensitive data is filtered
